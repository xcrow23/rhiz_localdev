ABLETON MCP INSTALLATION - Original (ahujasid/ableton-mcp)
========================================================

FALLBACK PLAN: uisato/ableton-mcp-extended has packaging bug (missing AbletonMCP_UDP directory)
Using battle-tested original instead.

INSTALLATION STEPS:
-------------------

Step 1: Install UV package manager
PowerShell command:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Step 2: Configure Claude Desktop
Edit: %APPDATA%\Claude\claude_desktop_config.json

Add this configuration:
{
  "mcpServers": {
    "AbletonMCP": {
      "command": "uvx",
      "args": ["ableton-mcp"]
    }
  }
}

Step 3: Install Remote Script in Ableton
Download from: https://github.com/ahujasid/ableton-mcp
Copy "Remote Scripts" folder contents to:
%USERPROFILE%\Documents\Ableton\User Library\Remote Scripts\

Folder should be named: AbletonOSC (not AbletonMCP for the original)

Step 4: Enable in Ableton Live
Preferences → Link, Tempo & MIDI
Control Surface: Select "AbletonOSC"
Input/Output: "None"

Step 5: Restart Everything
1. Fully quit Claude Desktop (not just close window)
2. Restart Claude Desktop
3. Launch Ableton Live with blank project
4. Check Claude Desktop developer settings for MCP tools

TESTING:
--------
Open Claude Desktop and ask: "Can you see my Ableton Live session?"
Should respond with session info if working.

NOTES:
------
- Original has 24 open issues but ~2,000 GitHub stars
- Largest community support (Discord available)
- No scene management features (vs extended version)
- Perfectly adequate for beat creation workflow
- Can upgrade to extended version later if needed
