## TELOS INTEGRATION POINTS

### Session Start
**Loads**: Relevant goals and KPIs for current domain
**Reminds**: Active problems we're solving
**Aligns**: Today's work with long-term mission

### Decision Making
**Traces**: Decisions back to problems/goals/mission
**Documents**: Using `decision_trace.md` pattern
**Questions**: "Which problem does this solve?" / "Which goal does this serve?"

### Conflict Resolution
**Reference**: Shared mission when disagreeing
**Appeals**: To problems we're trying to solve together
**Grounds**: In mutual purpose, not hierarchy

### Learning & Evolution
**Updates**: Goals based on what dyad discovers
**Adjusts**: KPIs based on reality
**Captures**: How problems/mission evolve over time
