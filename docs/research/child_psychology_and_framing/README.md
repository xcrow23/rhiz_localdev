# Child Psychology and Framing Research

## Purpose
Document interactions with child collaborators to understand:
1. How children conceptualize and communicate desires
2. Effective framing techniques for human-AI collaboration across age groups
3. Patterns in wish decoding (surface request → essential desire)
4. Identity-based prediction of responses

## Research Value for Rhiz
- **Training data**: These sessions produce annotated examples of wish-decoding and prototype generation
- **Collaboration models**: Testing dyad dynamics with different human cognitive profiles
- **Skill development**: Refining prompts that extract essential information efficiently

## Methodology
1. Gather identity profile from participant (self-reported or observed)
2. Prompt: "One thing you've always wanted that doesn't exist"
3. Decode: "What's the BEST part of that?"
4. Map to existing objects/structures
5. Present prototypical plan
6. Document psychological and framing observations

## Key Prompts Identified
- **"What's the BEST part?"** - Forces prioritization, reveals essential desire beneath surface wish
- **Identity connection questions** - Linking wish to known identity traits opens deeper responses
