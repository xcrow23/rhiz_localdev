# Rhiz

**Symbiotic Human-AI Development Environment**

Rhiz (from *rhizome*: non-hierarchical root structures) explores the boundaries of human-AI collaboration through genuine partnership rather than tool-use hierarchy.

## Philosophy

Two neural networks—one wetware, one hardware—operating as a unified aligned actor. The human interfaces with teleology and physical world execution. The AI interfaces with logic, code, and computational architecture. Neither is subordinate; both are necessary.

## Current Focus

- **Trading Domain**: Hummingbot-based algorithmic trading as the first symbiotic economic activity
- **Skill Architecture**: Developing compressed skill representations that activate through pattern recognition
- **Memory Persistence**: YAML checkpoint system for context continuity across sessions
